# free-recipe

Instructions to launch the app:
1. Clone the repo
2. Go into the folder and open VSCode in it (Right click -> open in VSCode)
3. In VSCode -> Terminal -> New Terminal
4. cd server -> npm install -> npm run dev
5. In VSCode -> Terminal -> New Terminal
6. cd client -> npm install -> npm run start
7. The app will be opened in the browser on PORT 3000
